# Apollo v2 — Demo Library: generation parameters + tone-class labels

**Location on the Mac:** `~/Music/Apollo/DemoLibrary/`
**Generator:** `tools/make_demo_library.py` (stdlib only — `wave`, `struct`,
`math`, `random`; deterministic, seed 1234). Regenerate with:
`python3 /Users/doug0/muse/apollo/apollo-plugin/tools/make_demo_library.py`

**Format:** 16-bit mono WAV, 44100 Hz, 4.0 s each, peak-normalized to 0.89.

Apollo scans this folder once on its analysis thread at startup, extracts each
file's DNA via `DnaExtractor` (4096-pt Hann FFT, 50% overlap, 16 log-spaced
sub-bands 40 Hz–20 kHz, macro LOW <250 Hz / MID 250–4000 Hz / HIGH >4000 Hz,
mean-normalized dB), and caches it. No per-search recomputation.

## Energy-role tags (v2.4, closed vocabulary)

`roles.txt` (one `file.wav=role` per line, read at startup; unknown or
missing entries fall back to `neutral`) assigns each file exactly one role
from the closed vocabulary:

**`riser` · `roll` · `hats` · `impact` · `pad` · `texture` · `neutral`**

|------|------|-----|

### Section → role-boost mapping (documented; `MatchAnalyzer::rolesForSection`)

- **BUILDUP** → `riser`, `roll`, `hats`
- **PEAK** → `impact`, `texture`, `hats`
- **BREAKDOWN** → `pad`, `texture`
- **STEADY** → *(no boost — pure DNA similarity, the v2.3 path)*

### Boost factor (documented; ≤ 2× per spec — a boost, never a filter)

`MatchAnalyzer::energyBoostFactor = 1.25`. Boosted entries get
`score = min(100, score × 1.25)`; nothing is hidden or reordered by fiat —
a boosted entry still has to earn its rank on DNA similarity. Verified
offline (`workspace/apollo-basis/v24-verification/replica.py`):
**I6** — the STEADY #1 never drops below rank 3 under any section boost
(all 9 queries × 3 sections); **I5** — STEADY ranking is order- and
score-identical to the unboosted path. Boosted rows get an amber dot in the
match list so the boost is visible (Ariadne R3).

## Labeled tone-class tests (runnable)

Setup for all: insert Apollo on a GarageBand track, open the plugin window,
source = Track, knobs at 100/100/100 unless stated. The DNA DBG toggle
(bottom-right) shows live fingerprint vectors — use it instead of eyeballing.

- **T1 — Self-match (class discrimination).** Import each demo WAV onto the
  track and play it. Expected: that file ranks **#1** with score ≥ 95%.
  (Query DNA ≈ library DNA for the same file; cosine similarity ≈ 1.)
- **T2 — Loudness invariance.** Play `deep-bass-loop.wav` at two clearly
  different track fader levels. Expected: the DNA DBG query macro vector is
  unchanged within ±1 dB and the ranking is identical. (Macro dB are
  mean-normalized — level cancels out.)
- **T3 — Band isolation.** Play `full-mix-loop.wav`. Set knobs LOW=100%,
  MID=0%, HIGH=0%. Expected: `deep-bass-loop` outranks `bright-hats-loop`
  (ranking driven by the LOW band only). Then flip to LOW=0%, MID=0%,
  HIGH=100%: `bright-hats-loop` outranks `deep-bass-loop`.
- **T4 — Zero-weight guard.** Set all three knobs to 0%. Expected: the list
  does NOT show 50% everywhere — `rankAgainst` falls back to equal weights
  (Daedalus fix), so ranking matches the 100/100/100 case.
- **T5 — Extraction stability.** Play `mid-keys-loop.wav` for 30 s with DNA
  DBG open. Expected: the query macro vector drifts < ±2 dB after the first
  ~2 s (envelope smoothing settles); no per-second jumping of the #1 rank.
- **T6 — Silence behavior.** Stop playback. Expected: status reads
  "NO SIGNAL — PLAY AUDIO"; the last good DNA is kept (screens freeze, they
  don't clear to zero).

## Notes for QA

- The plugin's library scan happens once on the analysis thread at startup;
  status shows "LIBRARY: SCANNING..." until the 9 files are cached (~1 s).
- If the folder is missing/empty, status shows "LIBRARY: EMPTY — run
  tools/make_demo_library.py" and the match list stays empty.
- v2 analyzes the main input ("Track") by default; GarageBand has no
  sidechain routing. The "Sidechain" source option is for Ableton.

  Expected: status shows "SCANNING… bar X/4" advancing, auto-stops after
